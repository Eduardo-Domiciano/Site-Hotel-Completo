# services

Servicos Angular compartilhados.

## Arquivos

| Arquivo | O que faz |
| --- | --- |
| `auth.ts` | Login, cadastro, JWT, perfil e logout. |
| `api.ts` | Chamadas HTTP a quartos, reservas, eventos e candidaturas. |
| `reservation.ts` | Estado do modal de reserva e POST na API. |
| `docdir.md` | Documentacao desta pasta. |

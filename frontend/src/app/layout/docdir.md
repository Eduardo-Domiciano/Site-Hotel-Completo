# layout

Componentes reutilizaveis da casca do site: navegacao, cabecalho, rodape, barra e modal de reserva.

## Arquivos

| Arquivo | O que faz |
| --- | --- |
| `docdir.md` | Documentacao desta pasta. |

## Subpastas

| Pasta | O que guarda |
| --- | --- |
| `site-nav/` | Menu principal no topo. |
| `page-header/` | Cabecalho com imagem e nome do hotel nas paginas internas. |
| `site-footer/` | Rodape com links, redes e contato. |
| `reservation-bar/` | Barra fixa de busca de reserva. |
| `reservation-modal/` | Janela de finalizar reserva. |

## Observacoes

- Esses componentes sao usados pelo `app` raiz, nao pelas paginas isoladas.
- Cada subpasta tem o seu proprio `docdir.md`.

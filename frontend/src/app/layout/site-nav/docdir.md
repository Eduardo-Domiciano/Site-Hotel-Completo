# site-nav

Menu principal fixo no topo, com destaque da rota ativa e menu mobile.

## Arquivos

| Arquivo | O que faz |
| --- | --- |
| `site-nav.ts` | Logica do menu: links, estado aberto/fechado no mobile. |
| `site-nav.html` | Markup da marca e dos links de navegacao. |
| `site-nav.css` | Estilos da barra e do menu recolhivel. |
| `docdir.md` | Documentacao desta pasta. |

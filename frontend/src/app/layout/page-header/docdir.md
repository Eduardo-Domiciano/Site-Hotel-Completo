# page-header

Cabecalho das paginas internas: fundo do hotel, nome e faixa de separacao.

## Arquivos

| Arquivo | O que faz |
| --- | --- |
| `page-header.ts` | Componente que expoe os dados do hotel. |
| `page-header.html` | Titulo e barra `.page-break` abaixo da imagem. |
| `page-header.css` | Estilos do hero curto das paginas internas. |
| `docdir.md` | Documentacao desta pasta. |

## Observacoes

- Usado em Sobre, Acomodacoes, Login e Trabalhe Conosco.
- A home tem hero proprio e nao usa este componente.

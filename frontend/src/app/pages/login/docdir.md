# login

Pagina de login e cadastro (demonstracao local, sem servidor).

## Arquivos

| Arquivo | O que faz |
| --- | --- |
| `login.ts` | Alterna abas, valida campos e escolhe fundo aleatorio. |
| `login.html` | Formularios de login e cadastro. |
| `login.css` | Estilos do card e das abas sobre o fundo fotografico. |
| `docdir.md` | Documentacao desta pasta. |

## Observacoes

- Rota: `/login`
- A barra de reservas fica oculta nesta pagina.

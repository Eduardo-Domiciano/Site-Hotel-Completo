# docs

Modelos e referencias de documentacao do projeto.

## Arquivos

| Arquivo | O que faz |
| --- | --- |
| `docdir.modelo.md` | Modelo padrao para criar `docdir.md` em qualquer pasta. |
| `docdir.md` | Documentacao desta pasta. |

## Observacoes

- A regra do Cursor em `.cursor/rules/docdir.mdc` aponta para este modelo.

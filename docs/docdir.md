# docs

Documentos do produto e o modelo de documentacao por pasta.

## Arquivos

| Arquivo | O que faz |
| --- | --- |
| `prd.md` | Requisitos do produto: o que o site faz hoje e o que ainda falta. |
| `drt.md` | Requisitos técnicos: arquitetura, API, dados, auth e deploy. |
| `docdir.modelo.md` | Modelo para criar um `docdir.md` em outra pasta. |
| `docdir.md` | Documentacao desta pasta. |

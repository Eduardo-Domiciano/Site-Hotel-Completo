# Site-Hotel-Completo

Projeto completo do Mikhalateia Hotel (front + API + Docker).

## Arquivos

| Arquivo | O que faz |
| --- | --- |
| `docker-compose.yml` | Sobe Postgres, API e Nginx (front). |
| `.env.example` | Variáveis de ambiente. |
| `README.md` | Como rodar o stack. |
| `docdir.md` | Documentação desta pasta. |

## Subpastas

| Pasta | O que guarda |
| --- | --- |
| `frontend/` | Aplicação Angular (cópia independente do SiteHotel demo). |
| `backend/` | API Go + migrations PostgreSQL. |
| `docker/` | Dockerfile do web e config Nginx. |
| `docs/` | PRD do produto e o modelo de `docdir.md`. |
